## Project description (under 600 characters)
Technical and on-page SEO for the Volleyball Champions League (VCL), a new sports league, so it
ranks first for its own fixtures, teams, scores and news. I set up indexing, sitemaps and crawl
paths, mapped league/team/fixture keywords, optimised match and schedule pages, added event and
organisation schema and wrote snippet-ready titles. Result: 34.1K clicks from 132K impressions at
avg. position 2.8 (25.9% CTR). Organic Search drives 88% of sessions, and 477 came from AI assistants.
