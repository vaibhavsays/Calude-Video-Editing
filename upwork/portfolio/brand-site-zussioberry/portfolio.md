## Project description (under 600 characters)
SEO for the Zussioberry brand website to grow non-branded search and rank key pages on page one.
I mapped keywords and intent to each page, optimised titles, metas, headings and internal links,
fixed technical and Core Web Vitals issues, built content around customer questions and earned
relevant backlinks. In 3 months: 178K impressions, 1.85K clicks, avg. position 6.9. Organic
Search is now the #1 channel (54.6% of sessions, 72.8% of engaged sessions).
